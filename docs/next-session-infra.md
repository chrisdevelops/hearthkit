Decisions already made for this run (interview on 2026-09-10, confirmed by the user):

The rest of the design, routine defaults the user has accepted:

- Resources, exactly four: `cloudflare_dns_record` (A), `cloudflare_r2_bucket` named `<project_name>`, `cloudflare_api_token` scoped to that one bucket with the R2 write permission group, `cloudflare_r2_bucket_cors` with one rule allowing `PUT` and `GET` from `https://<hostname>` with `content-type` allowed and `max_age_seconds = 3600`.
- Outputs, six: `hostname`, `storage_endpoint` (`https://<account_id>.r2.cloudflarestorage.com`), `storage_bucket`, `storage_access_key_id` (the token resource's `id`), `storage_secret_access_key` (`sha256(<token value>)`, sensitive), `dsn_hint`. The cli maps the first five onto `STORAGE_ENDPOINT`, `STORAGE_BUCKET`, `STORAGE_ACCESS_KEY_ID`, `STORAGE_SECRET_ACCESS_KEY`, and `STORAGE_REGION=auto`.
- State: the OpenTofu `s3` backend against R2, bucket `hearthkit-tofu-state`, key `<project_name>.tfstate`, region `auto`, endpoint from `account_id`; encryption with a `pbkdf2` key provider fed by `HEARTHKIT_TOFU_STATE_PASSPHRASE` through `TF_VAR_`, method `aes_gcm`. The cli passes the two state credentials as `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` in the child environment of `tofu init` only, and the backend config as `-backend-config` flags, so nothing secret lands in a file.
- `create` writes `infra/tofu.tfvars` with `project_name` filled and `zone_name`, `zone_id`, `account_id`, `host_ip` as empty-string placeholders on their own lines with a one-line comment each. Its scaffold gate at packages/create/src/create-hearthkit-project-tree.test.ts line 140 pins the exact tfvars text and its CONTRACT.md lines 44, 52 and 80 say the file carries one assignment; both change in this PR. `hearthkit infra apply` fails naming every blank variable before running `tofu`.
- `HEARTHKIT_INFRA_PROVIDER` accepts only `cloudflare`; unset or anything else fails before `tofu` runs.
- The cli shells out to `tofu` through the existing `run-child-process-command.ts`, with `-input=false -no-color`, and quotes `tofu`'s own stderr into the failure detail with the four secrets scrubbed the way payments scrubs its two.
